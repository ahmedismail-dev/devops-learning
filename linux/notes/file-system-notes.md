# Linux File System Navigation

This document contains useful Linux commands I practiced while learning
how to navigate the filesystem and work with files and directories.

## 1. `pwd`

### What it does

`pwd` stands for "print working directory".

It shows the absolute path of the directory I am currently in.

it's useful whem I'm unsure where I am in the filesystem

## 2. 'ls -lah'
### what it does
ls lists files and directories.

# the options add aditional information:
   -l = long/detailed format
   -a = show hidden files
   -h = human readable file sizes
# what i have learned is 'ls -lah' is useful for quickly inspecting a directory and seeing permissions, ownership, file sizes and file that are hidden.

## 3.  cd 
# what it does
  cd stands for "change directory"
  it allows me to move between directories. cd ~ = home directory
# what i have learned: cd is one of the most used commands when      working in the linux terminal.

## 4. cp 
# what it does
  it copies files or directories-
# what i have learned
  cp allows me to create a copy of a file while keeping the          original.

## 5. mv 
# what it does:
  mv moves files or directories, it can also be used to rename       files.
